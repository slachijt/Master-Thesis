The supplementary material includes the code and the data.

The code scripts are written in R version 4.5.2 and should run within a few minutes on a laptop CPU. The scripts produce full tables and full arrays of figures of which only a select few are chosen in the conference submission. 
The data is found in its original original form (GVT data.xls) downloaded directly from the Miller & Sanjurjo (2018) supplementary material, but can also be directly found in the code scripts under gvt_data.
